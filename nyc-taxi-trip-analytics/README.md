# NYC Taxi Trip Analytics

This project explores large-scale NYC Yellow Taxi trip data to identify temporal and geographic patterns in urban mobility. The analysis examines how taxi demand changes across hours and days of the week, how traffic conditions affect trip behavior, and how pickup activity is distributed across NYC Community Districts.

The notebook covers the complete analytical workflow, from data cleaning and feature engineering to statistical aggregation and geospatial analysis, using PySpark to efficiently process more than 11 million trip records.

## Tech Stack

**Python · PySpark · Spark SQL · Pandas · GeoPandas · Folium · Matplotlib · Seaborn**

**Key techniques:** large-scale data processing, data cleaning, feature engineering, temporal analysis, statistical aggregation, geospatial analysis, spatial joins, and data visualization.
# Dataset

This project uses the NYC Yellow Taxi Trip Records dataset.

The raw dataset is not included in this repository due to its file size.

To reproduce the analysis, download the January 2015 Yellow Taxi Trip Records
and place the CSV file in this directory as:

yellow_tripdata_2015-01.csv
